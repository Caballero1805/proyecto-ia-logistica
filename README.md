# Sistema Inteligente de Planificación Logística

## Descripción
Proyecto académico que integra búsqueda heurística, búsqueda local, metaheurísticas, teoría de juegos y búsqueda adversaria para resolver un problema logístico en una cuadrícula de 12×12.
